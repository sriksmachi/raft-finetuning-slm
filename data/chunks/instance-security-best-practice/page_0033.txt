# Best practices continued

## Implement logging and monitoring for the MID Server
Please review the specific logging and monitoring considerations below related to the MID Server and the [logging and monitoring section](#). Collaborate with stakeholders to develop a comprehensive logging and monitoring strategy.

- Consider enabling the MID Server Command Audit Log to track all executed commands.
- Monitor changes to sensitive roles (e.g., `discovery_admin`, `mid_server`) and alert on unauthorized modifications.
- Forward all log data to your internal SIEM platform for correlation and analysis. For detailed guidance on SIEM integration, refer to the [logging and monitoring section](#).
