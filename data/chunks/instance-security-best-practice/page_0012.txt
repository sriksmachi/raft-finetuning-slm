# Cloud infrastructure security management

## ServiceNow responsibility

ServiceNow is responsible for maintaining a secure architecture within customer cloud environments. This includes implementing hardened configurations and supporting processes to protect sensitive data and ensure system integrity. Security measures in place include firewalls, secure logical access controls, and intrusion detection systems. ServiceNow also continuously monitors systems for vulnerabilities and malicious activity.

As the SaaS Cloud Solution Provider, ServiceNow manages the cloud infrastructure to ensure availability, scalability, security, and performance. Responsibilities include:

- Developing and enforcing security policies and controls
- Monitoring for potential threats
- Implementing access controls
- Ensuring compliance with applicable regulations and industry standards

Additional responsibilities include conducting security assessments, performing penetration testing, and responding promptly to potential security incidents.

---

## Best practices

### Review and understand cloud infrastructure security management at ServiceNow

Establish a structured process to regularly review the ServiceNow cloud infrastructure security management documentation. Ensure all relevant stakeholders are engaged in these reviews to maintain alignment, compliance, and awareness of security practices.
